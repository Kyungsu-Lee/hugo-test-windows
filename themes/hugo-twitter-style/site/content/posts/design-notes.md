title = "A blog that reads like a profile"
date = 2026-06-07T14:30:00+09:00
description = "The theme borrows the structure of a current X profile and adapts it for a Hugo blog."
tags = ["design", "timeline"]
+++

The layout combines a profile header, cover area, avatar, action button, tab navigation, and timeline into a single blogging interface.

Profile values come from Hugo `params`, so the display name, handle, bio, location, website, join date, and avatar can be changed without editing templates.

The content remains ordinary Hugo Markdown. The theme changes how posts are presented, not how authors write them.
